# JourneyOS – AI Travel RPG

> **Your next adventure begins before you leave home.**

JourneyOS is a modern travel planner rebuilt as a retro 8-bit pixel RPG. Instead of filling out spreadsheets, users customize an adventurer class, speak to the AI Guild Master, explore an overworld map to unlock destination kingdom portals, and manage their trip via quest logs, gold budgets, and grid inventories.

## Features

- 🎮 **Start Menu & Character Creator**: Customize names, select unique classes (Explorer, Scholar, Merchant, Bard) with passive perks, clothes skins, difficulty settings, and custom companion pets.
- 🧙‍♂️ **AI Guild Master Hall**: Proceed through text-by-text dialogues to build custom itineraries based on destination, budget, duration, and style.
- 🗺️ **Canvas 2D Overworld Map**: Explore map paths using keyboard controls (WASD/Arrows), featuring stardust particle companions, weather overlays (rain, snow, heat), and starlit day/night cycle filters.
- 📜 **Quest Log (Itinerary)**: Interactive day-wise quests. Toggling quest checkboxes awards GP, XP, and triggers level ups.
- 👛 **Gold Wallet (Budget)**: RPG budgeting system. Book flight suggestions as travel portals and hotel stays as inn reservations using Gold.
- 🎒 **Backpack Inventory (Checklist)**: Packing items organized in grid slots with tooltips explaining item statistics.
- 🛃 **Passport & Achievements**: Displays unlocked kingdoms as vintage stamps and awards badges (Explorer, Food Hunter, etc.) based on game progress.
- 🎪 **Guild Bazaar**: Spend leftover gold to purchase custom pets or backpack cosmetics.
- 🎹 **Web Audio 8-Bit Synthesizer**: Generates chiptune SFX and background melodies dynamically.

## Tech Stack

- **Core**: React, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Synth**: Web Audio API

## Getting Started

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
